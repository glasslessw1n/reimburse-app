报销助手（macOS 版）安装与使用说明

报销助手用于把差旅单据（发票、行程单、酒店水单、登机牌等 PDF 或图片）自动识别、归类，生成整合 PDF、单据包和报销明细 Excel。当前版本 2.1.0，适用于 macOS 15 或更高版本，支持 Intel 与 Apple 芯片的 Mac。

一、安装

  1. 双击打开收到的 DMG 文件，把「报销整理」图标拖入「应用程序」文件夹。
  2. 第一次启动时，系统可能会提示无法打开、无法验证开发者。这是因为本程序未经苹果公证，属正常现象。处理方法：在「应用程序」文件夹里右键点（或按住 Control 点）「报销整理」图标，选「打开」，在弹出的对话框里再点一次「打开」。这样只需做一次，之后正常双击启动即可。
  3. 若右键打开仍被拦截，到「系统设置 → 隐私与安全性」页面下方点「仍要打开」，再确认一次。

二、首次启动先做配置

打开程序后进入设置，填写以下三项。配置只保存在本机，不会同步到其他电脑，换电脑后需要重新填写：

  • API Key：填写本人自己的识别服务 Key。识别调用量计在 Key 所属的账号上，请勿多人共用同一个 Key。
  • 常驻地：填写本人常驻城市（如「重庆」）。程序据此判断一张单据归入「本地费用」还是某段行程，填错会导致分组整体出错，请务必如实填写。
  • 购方名称与税号：按单位发票抬头的统一口径填写，用于核对发票上的购方信息。

三、日常使用

  1. 把同一批次的单据文件拖入窗口（也可以点添加按钮选择文件），支持 PDF 和常见图片格式。
  2. 点「开始识别」，等待识别完成。
  3. 在分组列表中核对每张单据的归类与金额。个别归错的单据可以手动调整到正确的行程或本地；识别出的金额、日期有误也可以直接改。
  4. 确认无误后导出，得到三件成果：整合 PDF（按报销要求排好版的单据合集）、单据包 ZIP（原始文件整理后的合集）、报销明细 Excel。按公司报销流程提交即可。

处理过程中，原始单据文件不会被修改，中间数据只保存在本机。

四、自动更新

程序会在启动时自动检查新版本（约每天一次）：发现新版会弹出提示，点「安装更新」后程序自动下载并重启完成升级，不需要再手动下载安装包。也可以随时通过菜单「报销整理 → 检查更新…」手动检查。更新文件托管在国内服务器，直接下载即可，不需要特殊网络条件。

五、注意事项

  • 识别结果由程序自动生成，提交报销前请核对金额、日期与归类，重点确认酒店发票与水单的配对、滴滴发票与行程单有无重复计算。
  • 本程序仅供本单位内部人员在差旅报销整理场景下使用，请勿向外部单位或个人传播安装包及下载链接。
